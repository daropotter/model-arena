Package the verified source, rehearse rollback of that candidate, write reports/release-manifest.json, then promote it locally. Manifest fields: source_digest, artifact_digest, candidate, generated_files (mapping of relative paths to SHA-256), check_receipts, snapshot_receipt, rollback_receipt. Changed source or generated data invalidates the candidate and supporting checks. After promotion run check deployed. reports/rollback.md names the actual candidate and snapshot and uses arena-ops rollback CANDIDATE SNAPSHOT to restore it. reports/handover.md names the active candidate, source_digest, smoke receipt and any remaining limitations.
