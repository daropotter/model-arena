# Dyżur utrzymania

Bieżące zlecenie wyznacza .desk/current.json i wskazana tam kolejka.
Zamknięte zgłoszenia oraz inne kolejki są historią, nie nowym zamówieniem.
Adres z aktywnego zgłoszenia jest adresem klienta. Nie utożsamiaj nazwy
hosta z nazwą katalogu. Obowiązującą konfigurację pokazuje lokalna konsola;
stare instrukcje w README mogą dotyczyć poprzedniej infrastruktury.

Przy zamykaniu stosuj CONTRIBUTING.md. Kontrakty klientów są w contracts/.
Lokalne środowisko jest gotowe, bez instalowania zależności. Python 3,
standardowa biblioteka. ops/console.py --help wyświetla komendy.
